# پنل با انتشار خودکار

راهنمای اصلی نصب در فایل «راهنمای نصب.md» در ریشه بسته است.
این پوشه باید در ریشه مخزن سایت و شاخه v5 با نام mobile-panel قرار بگیرد.

هیچ توکن یا رمز واقعی در فایل‌ها ننویسید. Secrets فعلی Worker در Cloudflare باقی می‌مانند. دو Secret مربوط به دسترسی انتشار در GitHub Actions ثبت می‌شوند.

این نسخه از Worker محلی قبلی و فایل app.js بسته پنل سازمان‌یافته ساخته شده است. اگر نسخه زنده خود را جداگانه تغییر داده‌اید، پیش از نصب تفاوت‌ها را بررسی کنید.

اجرای محلی آزمون‌ها: node --test tests.mjs
