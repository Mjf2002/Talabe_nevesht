مدیریت «منِ جمعی»

پنل شخصی و آفلاین شما — نوشته‌ها مستقیماً در پوشهٔ پروژه ذخیره می‌شوند. هیچ اطلاعاتی به سرور ارسال نمی‌شود.

با Chrome یا Edge در کامپیوتر باز کنید. پوشه‌ای را انتخاب کنید که content داخل آن است.

برای تیتر: ## عنوان | برای تأکید: **عبارت** | برای لینک: [متن](نشانی)

ذخیره، انتشار نیست. پس از ذخیره، در GitHub Desktop تغییرات را Commit و Push کنید.

ساخت موضوع و باکس جدید
راهنمای مستقل
  1. پیش از کار، در GitHub Desktop گزینهٔ Fetch origin و در صورت نیاز Pull origin را بزنید.
  2. پوشهٔ همان مخزن را در این پنل انتخاب کنید.
  3. موضوع را بسازید یا یادداشت موجود را انتخاب کنید و تغییر دهید.
  4. «ذخیره در پروژه» را بزنید.
  5. در GitHub Desktop فایل‌های تغییرکرده را بررسی کنید؛ Summary را بنویسید و Commit سپس Push origin را بزنید.
  6. در GitHub، بخش Actions را بررسی کنید؛ پس از موفقیت، سایت را تازه کنید.

اگر پشیمان شدید، پیش از Commit از Discard changes در GitHub Desktop فقط برای فایل موردنظر استفاده کنید؛ این کار تغییرات ذخیره‌نشده در تاریخچه را پاک می‌کند. برای تغییرات منتشرشده از Revert commit استفاده کنید و سپس Push کنید.

تا وقتی ذخیره نکرده‌اید صفحه را نبندید. فونت این پنل فونت سیستم است و فونت سایت را تغییر نمی‌دهد. ویرایشگر متنی Markdown است، نه ویرایشگر بصری. حذف، جابه‌جایی و تغییر نام نوشته‌ها عمداً در این نسخه نیست تا لینک‌های سایت آسیب نبینند.
